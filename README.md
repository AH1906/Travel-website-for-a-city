## Overview

The site showcases Detroit as a travel destination across four linked pages, each focused on a different aspect of visiting the city: an overview with visitor reviews, places to see, transport options, and travel tips. The layout is fully responsive, adapting cleanly between desktop and mobile screens.

## Pages

- **Home (`index.html`)** — Introduction to Detroit, key facts about the city, and visitor reviews
- **Places (`places.html`)** — Notable places and attractions to visit
- **Transport (`transport.html`)** — Getting around the city
- **Travel Tips (`travel-tips.html`)** — Practical tips for visitors

All pages share a consistent header and navigation bar, so users can move between sections easily.

## Features

- Responsive layout that works across mobile and desktop devices
- Consistent navigation bar linking all four pages
- Image galleries with descriptive alt text for accessibility
- Visitor review section with photos and quotes
- Image and content credits included in the footer of each page

## Tech Stack

- **HTML5** — page structure and semantic markup
- **CSS3** — styling and responsive layout (`styles.css`)

## Running Locally

No build tools or dependencies are required. Clone the repository and open `index.html` in any web browser:

git clone https://github.com/AH1906/Travel-website-for-a-city.git
cd Travel-website-for-a-city

Then open `index.html` directly, or serve the folder locally, e.g.:

python -m http.server
